유니온 파인드 · MST

집합의 연결 여부를 빠르게 관리하고, 모든 노드를 잇는 최소 비용 구조를 만듭니다.

집합사이클크루스칼

이 신호를 찾으세요

  • 두 노드가 같은 그룹인지 묻는다
  • 간선을 추가하며 사이클을 검사한다
  • 모든 지점을 최소 비용으로 연결한다
대표 문제

모든 도시를 최소 비용으로 연결

A, B, C, D를 잇는 간선 중 전체를 연결하면서 비용 합이 최소인 간선을 고르세요.

입력
AB=1, BC=2, AC=3, CD=4, BD=5
출력
AB, BC, CD — 총비용 7
핵심 생각

크루스칼 알고리즘은 간선을 비용순으로 보고, 서로 다른 집합을 잇는 간선만 선택합니다. 유니온 파인드로 두 노드가 이미 연결됐는지 빠르게 검사합니다.

  1. 간선 정렬

    AB, BC, AC, CD, BD 순서로 비용이 작은 간선부터 봅니다.

  2. 사이클 방지

    find(u)와 find(v)가 같으면 이미 이어져 있으므로 그 간선은 제외합니다.

  3. 완성 조건

    노드가 4개면 간선 3개를 선택하는 순간 최소 신장 트리가 완성됩니다.

알고리즘 실행 과정
1 / 4
처음에는 모두 다른 집합

각 노드의 대표는 자기 자신입니다. 가장 싼 AB=1을 선택해 A와 B를 합칩니다.

간선
AB 1BC 2AC 3CD 4BD 5
집합
{A,B}{C}{D}
cost
1
BC=2 선택

B와 C는 다른 집합이므로 간선을 선택하고 {A,B,C}로 합칩니다.

간선
AB 1BC 2AC 3CD 4BD 5
집합
{A,B,C}{D}
cost
3
AC=3 제외

A와 C의 대표가 이미 같습니다. AC를 추가하면 사이클이 생기므로 제외합니다.

간선
AB 1BC 2AC 3CD 4BD 5
선택
ABBC
CD=4 선택해 완성

C와 D는 다른 집합이므로 선택합니다. 간선 3개로 모든 노드가 연결되고 총비용은 7입니다.

간선
AB 1BC 2AC 3CD 4BD 5
집합
{A,B,C,D}
cost
7
이 문제의 전체 코드
def kruskal(nodes, edges):
    parent = {node: node for node in nodes}
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]
    chosen, cost = [], 0
    for weight, a, b in sorted(edges):
        root_a, root_b = find(a), find(b)
        if root_a != root_b:
            parent[root_b] = root_a
            chosen.append((a, b))
            cost += weight
    return chosen, cost
function kruskal(nodes, edges) {
  const parent = Object.fromEntries(nodes.map(node => [node, node]));
  const find = x => parent[x] === x ? x : (parent[x] = find(parent[x]));
  const chosen = [];
  let cost = 0;
  edges.sort((a, b) => a[0] - b[0]);
  for (const [weight, a, b] of edges) {
    const rootA = find(a), rootB = find(b);
    if (rootA !== rootB) {
      parent[rootB] = rootA;
      chosen.push([a, b]);
      cost += weight;
    }
  }
  return { chosen, cost };
}

풀이 순서

  1. 각 노드의 대표를 자기 자신으로 초기화한다.
  2. find에 경로 압축을 적용한다.
  3. MST는 간선을 비용순으로 보며 다른 집합일 때만 합친다.

복잡도

유니온 파인드 거의 O(1), 크루스칼 O(E log E)

function find(x) {
  if (parent[x] !== x) parent[x] = find(parent[x]);
  return parent[x];
}

function union(a, b) {
  a = find(a);
  b = find(b);
  if (a !== b) parent[b] = a;
}
