최단 경로

가중치가 있는 그래프에서 시작점부터 각 노드까지의 최소 비용을 갱신합니다.

다익스트라가중치우선순위 큐

이 신호를 찾으세요

  • 도로마다 비용이 다르다
  • 한 지점에서 다른 지점까지 최소 비용을 구한다
  • 음수가 아닌 가중치가 주어진다

적용 조건

  • 다익스트라는 모든 간선 가중치가 0 이상이어야 합니다.
  • 모든 노드는 인접 간선이 없어도 graph의 키로 존재하고, 우선순위 큐는 최소 비용 항목을 먼저 꺼내야 합니다.

이 방법이 맞지 않는 경우

  • 가중치가 모두 같으면 BFS가 더 단순하고, 음수 간선이 있으면 Bellman–Ford나 DAG 최단 경로를 검토합니다.
  • 모든 쌍의 거리나 경유 횟수 제한이 있으면 상태와 알고리즘을 별도로 설계합니다.
대표 문제

가중치 그래프의 최단 거리

S에서 모든 노드까지의 최소 비용을 구하세요. 간선은 S-A 4, S-B 1, B-A 2, A-C 1, B-C 5입니다.

입력
start = S
출력
S=0, B=1, A=3, C=4
입력 조건
모든 가중치는 0 이상이고 모든 노드는 빈 인접 목록이라도 graph의 키로 존재합니다. graph는 방향 그래프 인접 리스트입니다.
시간 복잡도
인접 리스트 + 이진 최소 힙 기준 O((V + E) log V)
공간 복잡도
dist와 힙 O(V + E), 입력 그래프 O(V + E)
핵심 생각

다익스트라는 현재까지 거리가 가장 짧은 노드를 확정하고, 그 노드를 거쳐 이웃으로 가는 비용이 더 작으면 갱신합니다.

  1. 거리 초기화

    시작점은 0, 나머지는 무한대로 두고 (0,S)를 우선순위 큐에 넣습니다.

  2. 최소 후보 확정

    큐에서 거리가 가장 작은 노드를 꺼내 이웃 간선을 완화합니다.

  3. 낡은 항목 건너뛰기

    큐에서 꺼낸 비용이 최신 dist보다 크다면 이미 더 좋은 경로가 있으므로 무시합니다.

알고리즘 실행 과정
1 / 4
S에서 시작

S를 비용 0으로 확정하고 직접 연결된 A=4, B=1을 후보로 넣습니다.

dist
S 0A 4B 1C ∞
queue
B 1A 4
가장 가까운 B 확정

B까지 1입니다. B→A를 거치면 1+2=3으로 기존 4보다 짧아 A를 3으로 갱신합니다. C도 6이 됩니다.

dist
S 0A 3B 1C 6
queue
A 3A 4(낡음)C 6
A를 거쳐 C 갱신

A를 비용 3으로 확정합니다. A→C를 거치면 3+1=4로 기존 6보다 짧습니다.

dist
S 0A 3B 1C 4
queue
C 4C 6(낡음)
모든 최단 거리 확정

C를 비용 4로 확정합니다. 큐의 낡은 A=4와 C=6은 최신 거리와 달라 건너뜁니다.

dist
S 0A 3B 1C 4
이 문제의 전체 코드
import heapq

def dijkstra(graph, start):
    dist = {node: float("inf") for node in graph}
    dist[start] = 0
    heap = [(0, start)]
    while heap:
        cost, node = heapq.heappop(heap)
        if cost != dist[node]:
            continue
        for next_node, weight in graph[node]:
            next_cost = cost + weight
            if next_cost < dist[next_node]:
                dist[next_node] = next_cost
                heapq.heappush(heap, (next_cost, next_node))
    return dist
function dijkstra(graph, start, heap) {
  const dist = Object.fromEntries(Object.keys(graph).map(node => [node, Infinity]));
  dist[start] = 0;
  heap.push([0, start]);
  while (!heap.isEmpty()) {
    const [cost, node] = heap.popMin();
    if (cost !== dist[node]) continue;
    for (const [next, weight] of graph[node]) {
      const nextCost = cost + weight;
      if (nextCost < dist[next]) {
        dist[next] = nextCost;
        heap.push([nextCost, next]);
      }
    }
  }
  return dist;
}

풀이 순서

  1. 간선 가중치가 음수가 아닌지 확인한다.
  2. 가장 가까운 미확정 노드를 우선순위 큐에서 꺼낸다.
  3. 이미 더 짧은 거리로 처리한 항목은 건너뛴다.

복잡도

인접 리스트 + 이진 최소 힙 기준 O((V + E) log V), 공간 O(V + E)
  • heap은 push([비용, 노드]), popMin(), isEmpty() 계약을 제공해야 합니다.

자주 하는 실수

우선순위 큐에 같은 노드가 여러 번 들어갈 수 있으므로 꺼낸 거리와 최신 거리를 비교하세요.
