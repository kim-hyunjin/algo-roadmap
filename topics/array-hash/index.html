01기초

배열 · 해시

값의 존재 여부, 빈도, 빠른 조회가 핵심일 때 가장 먼저 떠올릴 도구입니다.

빈도중복평균 O(1) 조회

이 신호를 찾으세요

  • 값의 등장 횟수를 세어야 한다
  • 중복 여부를 빠르게 확인한다
  • 두 값의 관계를 즉시 조회한다

적용 조건

  • 키의 동등성 기준이 문제와 맞아야 합니다.
  • 저장할 키의 수만큼 추가 메모리를 사용할 수 있어야 합니다.

이 방법이 맞지 않는 경우

  • 정렬 순서나 값의 범위 질의가 핵심이면 정렬, 트리, 누적 구조가 더 알맞을 수 있습니다.
  • 해시 조회의 엄격한 최악 시간 보장이 필요한 상황에는 그대로 의존하지 않습니다.
대표 문제

두 수의 합

정수 배열에서 합이 target이 되는 서로 다른 두 원소의 인덱스를 찾으세요.

입력
nums = [2, 7, 11, 15], target = 9
출력
[0, 1]
입력 조건
정수 배열에서 서로 다른 두 인덱스를 사용합니다. 답이 없으면 빈 배열을 반환합니다.
시간 복잡도
평균 O(N)
공간 복잡도
O(N)
핵심 생각

현재 값 x를 볼 때 필요한 값 target - x가 앞에서 등장했는지만 해시에서 찾습니다. 모든 쌍을 다시 비교하지 않아도 됩니다.

  1. 필요한 값 계산

    x와 더해 target이 될 값인 target - x를 계산합니다.

  2. 먼저 조회

    필요한 값이 해시에 있으면 이전 인덱스와 현재 인덱스가 정답입니다.

  3. 나중에 저장

    정답이 아니라면 현재 값과 인덱스를 저장하고 다음 원소로 갑니다.

알고리즘 실행 과정
1 / 2
2를 확인합니다

9 - 2 = 7이 필요하지만 해시가 비어 있습니다. 2의 인덱스 0을 저장합니다.

이 문제의 전체 코드
def two_sum(nums, target):
    seen = {}
    for index, value in enumerate(nums):
        need = target - value
        if need in seen:
            return [seen[need], index]
        seen[value] = index
    return []
function twoSum(nums, target) {
  const seen = new Map();
  for (let index = 0; index < nums.length; index++) {
    const need = target - nums[index];
    if (seen.has(need)) return [seen.get(need), index];
    seen.set(nums[index], index);
  }
  return [];
}

풀이 순서

  1. 키와 값이 무엇인지 정한다.
  2. 한 번 순회하며 빈도나 위치를 저장한다.
  3. 두 번째 순회 또는 즉시 조회로 답을 만든다.

복잡도

평균 O(N), 보조 공간 O(N)
  • 해시 조회와 갱신은 평균 O(1)이며 충돌이 심한 최악의 경우는 구현에 따라 달라집니다.

자주 하는 실수

Python 딕셔너리 키는 hashable해야 합니다. JavaScript Map의 객체 키는 내용이 아니라 객체 동일성으로 비교됩니다.

문제에 맞춰 완성하는 기본 골격

정의되지 않은 변수와 함수는 문제의 입력·상태·반환 규칙에 맞게 채워야 합니다.

count = {}
for value in values:
    count[value] = count.get(value, 0) + 1
const count = new Map();
for (const value of values) {
  count.set(value, (count.get(value) ?? 0) + 1);
}
