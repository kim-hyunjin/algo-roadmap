동적 계획법

겹치는 작은 문제의 답을 저장해 같은 계산을 반복하지 않습니다.

상태
점화식
메모이제이션
이 신호를 찾으세요
  • 경우의 수, 최댓값, 최솟값을 구한다
  • 현재 답이 이전 상태의 답으로 표현된다
  • 재귀 호출에 같은 인자가 반복된다
적용 조건
  • 같은 부분 문제가 반복되고 큰 문제의 답을 작은 문제의 답으로 구성할 수 있어야 합니다.
  • 상태가 답을 결정하는 데 필요한 정보를 빠짐없이 담아야 합니다.
이 방법이 맞지 않는 경우
  • 최댓값·최솟값을 묻는다는 이유만으로 DP를 확정하지 않습니다.
  • 상태 수가 너무 크면 상태 압축, 다른 관찰, 그리디 가능성을 검토합니다.
대표 문제
계단 오르기

한 번에 1칸 또는 2칸을 오를 수 있을 때 n번째 계단에 도달하는 방법의 수를 구하세요.

입력
n = 5
출력
8
입력 조건
n은 0 이상의 정수입니다. n = 0은 아무것도 하지 않는 한 가지 방법으로 셉니다.
시간 복잡도
O(N)
공간 복잡도
O(N), 직전 두 값만 저장하면 O(1)로 축소 가능
핵심 생각

n번째 계단의 마지막 이동은 n-1에서 1칸 오거나 n-2에서 2칸 오르는 두 경우뿐입니다. 따라서 dp[n] = dp[n-1] + dp[n-2]입니다.

  1. STEP 01상태 정의

    dp[i]를 i번째 계단에 도달하는 방법의 수로 정합니다.

  2. STEP 02초깃값

    0번째에는 아무것도 하지 않는 1가지, 1번째에는 1칸 오르는 1가지가 있습니다.

  3. STEP 03작은 답 재사용

    2부터 n까지 앞의 두 값을 더해 한 번씩만 계산합니다.

이 문제의 전체 코드

언어를 바꿔가며 풀이를 비교해 보세요.

def climb_stairs(n):
    if n <= 1:
        return 1
    dp = [0] * (n + 1)
    dp[0] = dp[1] = 1
    for stair in range(2, n + 1):
        dp[stair] = dp[stair - 1] + dp[stair - 2]
    return dp[n]
function climbStairs(n) {
  if (n <= 1) return 1;
  const dp = Array(n + 1).fill(0);
  dp[0] = dp[1] = 1;
  for (let stair = 2; stair <= n; stair++) {
    dp[stair] = dp[stair - 1] + dp[stair - 2];
  }
  return dp[n];
}
#include <vector>

long long climbStairs(int n) {
  if (n <= 1) return 1;
  std::vector<long long> dp(n + 1);
  dp[0] = dp[1] = 1;
  for (int stair = 2; stair <= n; ++stair) {
    dp[stair] = dp[stair - 1] + dp[stair - 2];
  }
  return dp[n];
}

풀이 순서
  1. dp 상태가 의미하는 문장을 먼저 쓴다.
  2. 이전 상태에서 현재 상태로 오는 점화식을 만든다.
  3. 초깃값과 계산 순서를 정한다.
