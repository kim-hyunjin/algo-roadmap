04기초

정렬 · 그리디

매 순간의 최선이 전체 최선으로 이어지는 근거를 찾고, 선택 기준대로 정렬합니다.

선택 기준정렬증명

이 신호를 찾으세요

  • 최소 횟수나 최대 개수를 구한다
  • 앞의 선택이 뒤의 선택 범위를 결정한다
  • 구간을 가능한 많이 고른다

적용 조건

  • 국소 선택이 전체 최적해를 해치지 않는다는 교환 논법이나 불변식을 설명할 수 있어야 합니다.
  • 회의 예시는 [start, end) 구간으로 보며 end와 다음 start가 같으면 겹치지 않습니다.

이 방법이 맞지 않는 경우

  • 현재 최선 선택이 미래 선택지를 망치는 반례가 있으면 DP나 탐색을 검토합니다.
  • 정렬 기준을 바꿨을 때 결과가 달라지면 그 기준의 정당성을 먼저 증명해야 합니다.
대표 문제

겹치지 않는 회의 최대 선택

시작·종료 시간이 주어진 회의 중 서로 겹치지 않게 가장 많은 회의를 고르세요.

입력
meetings = [(1,3), (2,5), (4,6), (6,7)]
출력
3개: (1,3), (4,6), (6,7)
입력 조건
회의는 [start, end) 구간입니다. end와 다음 start가 같으면 겹치지 않으며 코드는 입력 배열을 정렬합니다.
시간 복잡도
O(N log N)
공간 복잡도
선택 결과 O(N), 정렬 보조 공간은 언어 구현에 따라 다름
핵심 생각

가장 빨리 끝나는 회의를 고르면 뒤에 남는 시간이 최대가 됩니다. 종료 시간순으로 정렬하고, 직전에 고른 회의가 끝난 뒤 시작하는 회의만 선택합니다.

  1. 선택 기준

    시작 시간이 아니라 종료 시간이 빠른 순서로 정렬합니다.

  2. 겹침 검사

    회의 시작이 lastEnd 이상이면 선택하고 lastEnd를 갱신합니다.

  3. 왜 안전한가

    더 늦게 끝나는 회의를 골라도 이후 선택지가 늘지 않으므로 빠른 종료가 손해가 아닙니다.

알고리즘 실행 과정
1 / 3

(1,3)을 선택하고 lastEnd를 3으로 둡니다.

(2,5)는 2 < 3이므로 이미 고른 회의와 겹쳐 제외합니다.

이 문제의 전체 코드

언어를 바꿔가며 풀이를 비교해 보세요.

def max_meetings(meetings):
    meetings.sort(key=lambda meeting: meeting[1])
    chosen, last_end = [], float("-inf")
    for start, end in meetings:
        if start >= last_end:
            chosen.append((start, end))
            last_end = end
    return chosen
function maxMeetings(meetings) {
  meetings.sort((a, b) => a[1] - b[1]);
  const chosen = [];
  let lastEnd = -Infinity;
  for (const meeting of meetings) {
    if (meeting[0] >= lastEnd) {
      chosen.push(meeting);
      lastEnd = meeting[1];
    }
  }
  return chosen;
}
#include <algorithm>
#include <limits>
#include <utility>
#include <vector>

std::vector<std::pair<int, int>> maxMeetings(
    std::vector<std::pair<int, int>> meetings) {
  std::sort(meetings.begin(), meetings.end(), [](const auto& a, const auto& b) {
    return a.second < b.second;
  });
  std::vector<std::pair<int, int>> chosen;
  int lastEnd = std::numeric_limits<int>::min();
  for (const auto& [start, end] : meetings) {
    if (start >= lastEnd) {
      chosen.push_back({start, end});
      lastEnd = end;
    }
  }
  return chosen;
}

풀이 순서

  1. 후보를 비교할 한 가지 기준을 찾는다.
  2. 교환 논법으로 그 선택이 손해가 아님을 설명한다.
  3. 정렬 후 한 번 순회하며 선택한다.

복잡도

정렬이 지배하면 O(N log N)
  • 제자리 정렬은 입력 순서를 바꾸므로 원본이 필요하면 복사본을 정렬합니다.
