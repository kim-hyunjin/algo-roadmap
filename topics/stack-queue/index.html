핵심 생각

여는 괄호는 스택에 쌓고, 닫는 괄호를 만나면 스택 맨 위와 짝이 맞는지 확인합니다. 가장 최근에 열린 괄호가 먼저 닫혀야 합니다.

  1. STEP 01여는 괄호 저장

    (, {, [를 만나면 스택의 맨 뒤에 넣습니다.

  2. STEP 02닫는 괄호 비교

    닫는 괄호의 짝이 스택 맨 위인지 확인한 뒤 꺼냅니다.

  3. STEP 03빈 스택 확인

    끝났을 때 스택이 비어 있어야 모든 괄호가 닫힌 것입니다.

function isValid(s) {
  const pairs = new Map([[")", "("], ["}", "{"], ["]", "["]]);
  const stack = [];
  for (const char of s) {
    if (!pairs.has(char)) stack.push(char);
    else if (stack.pop() !== pairs.get(char)) return false;
  }
  return stack.length === 0;
}
#include <stack>
#include <string>
#include <unordered_map>

bool isValid(const std::string& s) {
  const std::unordered_map<char, char> pairs = {
    {')', '('}, {'}', '{'}, {']', '['}
  };
  std::stack<char> stack;
  for (char ch : s) {
    auto found = pairs.find(ch);
    if (found == pairs.end()) {
      stack.push(ch);
    } else {
      if (stack.empty() || stack.top() != found->second) return false;
      stack.pop();
    }
  }
  return stack.empty();
}

  3. 꺼낼 때 비어 있는지 먼저 검사한다.
