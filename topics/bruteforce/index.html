03기초

완전 탐색 · 백트래킹

가능한 경우가 작고 모든 조합을 확인해야 할 때, 탐색 트리를 만들고 가지를 줄입니다.

조합순열가지치기

이 신호를 찾으세요

  • 입력 크기가 매우 작다
  • 모든 순서나 조합을 구한다
  • 조건을 만족하는 경우를 센다

적용 조건

  • 가능한 상태 수가 제한 시간 안에 탐색 가능한지 먼저 추정합니다.
  • 상태, 선택지, 종료 조건과 원상 복구 대상을 정의할 수 있어야 합니다.

이 방법이 맞지 않는 경우

  • 입력이 커서 지수적 상태 수를 모두 볼 수 없으면 DP, 그리디, 가지치기 강화가 필요합니다.
  • 중복 값이 있으면 같은 결과를 중복 생성하지 않을 규칙을 추가해야 합니다.
대표 문제

모든 부분집합

서로 다른 숫자 배열의 모든 부분집합을 만드세요.

입력
nums = [1, 2, 3]
출력
[1,2,3], [1,2], [1,3], [1], [2,3], [2], [3], [] (순서는 무관)
입력 조건
nums의 값은 서로 다릅니다. 부분집합의 나열 순서는 정답에 영향을 주지 않습니다.
시간 복잡도
O(N · 2ᴺ) — 각 결과 복사 비용 포함
공간 복잡도
출력 O(N · 2ᴺ), 재귀 보조 공간 O(N)
핵심 생각

각 숫자마다 ‘고른다’와 ‘고르지 않는다’ 두 갈래를 모두 탐색합니다. 선택한 뒤 재귀 호출하고, 돌아오면 선택을 취소해야 다른 갈래를 탐색할 수 있습니다.

  1. 상태 정의

    index는 결정할 숫자 위치, path는 지금까지 고른 숫자입니다.

  2. 두 갈래 탐색

    현재 숫자를 포함하는 재귀와 포함하지 않는 재귀를 모두 호출합니다.

  3. 원상 복구

    포함한 갈래가 끝나면 pop으로 선택을 취소한 뒤 제외 갈래로 이동합니다.

알고리즘 실행 과정
1 / 4
1을 선택합니다

첫 갈래에서 1을 path에 넣고 다음 숫자 2로 내려갑니다.

결정
1 선택2 ?3 ?
path
[1]
2와 3도 선택합니다

선택 갈래를 계속 따라가면 첫 결과 [1,2,3]을 얻습니다.

결정
1 선택2 선택3 선택
결과
[1,2,3]
3 선택을 되돌립니다

pop으로 3을 빼고 ‘3을 고르지 않는’ 갈래에서 [1,2]를 기록합니다.

결정
1 선택2 선택3 제외
결과
[1,2,3][1,2]
모든 갈래를 탐색합니다

같은 방식으로 2와 1도 되돌리면 2³ = 8개의 부분집합이 완성됩니다.

결과
[1,2,3][1,2][1,3][1][2,3][2][3][]
이 문제의 전체 코드

언어를 바꿔가며 풀이를 비교해 보세요.

def subsets(nums):
    answer, path = [], []
    def search(index):
        if index == len(nums):
            answer.append(path[:])
            return
        path.append(nums[index])
        search(index + 1)
        path.pop()
        search(index + 1)
    search(0)
    return answer
function subsets(nums) {
  const answer = [], path = [];
  function search(index) {
    if (index === nums.length) return answer.push([...path]);
    path.push(nums[index]);
    search(index + 1);
    path.pop();
    search(index + 1);
  }
  search(0);
  return answer;
}
#include <vector>

std::vector<std::vector<int>> subsets(const std::vector<int>& nums) {
  std::vector<std::vector<int>> answer;
  std::vector<int> path;

  auto search = [&](auto&& self, int index) -> void {
    if (index == static_cast<int>(nums.size())) {
      answer.push_back(path);
      return;
    }
    path.push_back(nums[index]);
    self(self, index + 1);
    path.pop_back();
    self(self, index + 1);
  };

  search(search, 0);
  return answer;
}

풀이 순서

  1. 상태, 선택지, 종료 조건을 정의한다.
  2. 선택하고 재귀 호출한 뒤 반드시 원상 복구한다.
  3. 답이 될 수 없는 상태는 일찍 종료한다.

복잡도

상태 수에 따라 O(2ᴺ), O(N!) 등, 재귀 보조 공간 O(N)
  • 결과 자체를 모두 반환하면 복사와 출력 크기도 시간·공간 복잡도에 포함합니다.

자주 하는 실수

백트래킹 후 방문 표시나 변경한 값을 복구하지 않는 실수를 가장 먼저 확인하세요.
