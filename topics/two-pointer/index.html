연속 구간이나 정렬된 배열에서 두 경계를 움직여 중복 계산을 없앱니다.

연속 구간
구간 합
두 경계
이 신호를 찾으세요
  • 연속된 부분 구간을 구한다
  • 두 수의 합이 목표에 가까워야 한다
  • 구간을 늘리고 줄이며 조건을 맞춘다
적용 조건
  • 슬라이딩 윈도우는 창을 확장·축소할 때 판정 조건이 단조롭게 변해야 합니다.
  • 현재 합 템플릿은 모든 원소가 양수인 연속 구간에 사용합니다.
이 방법이 맞지 않는 경우
  • 음수가 섞인 합 문제는 왼쪽을 줄여도 합이 한 방향으로 변하지 않아 현재 템플릿이 실패할 수 있습니다.
  • 정렬하면 원래 순서의 연속성이 깨지는 문제에서는 정렬 기반 투 포인터를 사용하지 않습니다.
대표 문제
합이 7 이상인 가장 짧은 연속 구간

양수 배열에서 합이 target 이상인 가장 짧은 연속 부분 배열의 길이를 구하세요.

입력
nums = [2, 3, 1, 2, 4, 3], target = 7
출력
2 — [4, 3]
입력 조건
nums의 모든 값과 target은 양수입니다. 답이 없으면 0을 반환합니다.
시간 복잡도
O(N)
공간 복잡도
O(1)
핵심 생각

오른쪽 포인터로 합을 늘리고, 조건을 만족하는 동안 왼쪽 포인터를 당겨 가장 짧은 구간을 찾습니다. 모든 값이 양수라 포인터 이동 방향이 안전합니다.

  1. STEP 01오른쪽 확장

    합이 7보다 작으면 right를 한 칸 이동해 새 값을 더합니다.

  2. STEP 02왼쪽 축소

    합이 7 이상이면 현재 길이를 기록하고 left 값을 빼며 줄입니다.

  3. STEP 03최솟값 갱신

    조건을 만족할 때마다 현재 구간 길이와 지금까지의 최솟값을 비교합니다.

이 문제의 전체 코드

언어를 바꿔가며 풀이를 비교해 보세요.

def min_subarray_len(nums, target):
    left = total = 0
    answer = len(nums) + 1
    for right, value in enumerate(nums):
        total += value
        while total >= target:
            answer = min(answer, right - left + 1)
            total -= nums[left]
            left += 1
    return 0 if answer > len(nums) else answer
function minSubarrayLen(nums, target) {
  let left = 0, sum = 0, answer = Infinity;
  for (let right = 0; right < nums.length; right++) {
    sum += nums[right];
    while (sum >= target) {
      answer = Math.min(answer, right - left + 1);
      sum -= nums[left++];
    }
  }
  return answer === Infinity ? 0 : answer;
}
#include <algorithm>
#include <limits>
#include <vector>

int minSubarrayLen(const std::vector<int>& nums, int target) {
  int left = 0;
  int sum = 0;
  int answer = std::numeric_limits<int>::max();
  for (int right = 0; right < static_cast<int>(nums.size()); ++right) {
    sum += nums[right];
    while (sum >= target) {
      answer = std::min(answer, right - left + 1);
      sum -= nums[left++];
    }
  }
  return answer == std::numeric_limits<int>::max() ? 0 : answer;
}

풀이 순서
  1. 왼쪽과 오른쪽 포인터의 의미를 정한다.
  2. 어떤 조건에서 어느 포인터가 움직이는지 결정한다.
  3. 포인터가 움직일 때 합이나 빈도를 증분 갱신한다.
복잡도
두 포인터가 각각 최대 N번 이동하면 O(N), 보조 공간 O(1) 또는 빈도표 크기
  • 정렬된 배열의 양끝 포인터와 원래 순서의 슬라이딩 윈도우는 서로 다른 전제 조건을 사용합니다.
