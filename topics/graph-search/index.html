연결 관계를 따라가며 모든 상태를 방문하거나, 간선 비용이 같을 때 최단 단계를 찾습니다.

그래프격자최단 단계

이 신호를 찾으세요

  • 서로 연결된 영역을 센다
  • 상하좌우로 이동한다
  • 최소 이동 횟수를 구하고 모든 이동 비용이 같다
대표 문제

격자에서 최단 거리 찾기

0은 이동 가능, 1은 벽인 격자에서 S부터 G까지 상하좌우 최소 이동 횟수를 구하세요.

입력
S 0 1 / 1 0 0 / 0 0 G
출력
4
핵심 생각

모든 이동 비용이 1이므로 BFS를 사용합니다. 시작점에서 가까운 칸부터 큐로 처리하면 목표를 처음 방문한 거리가 곧 최단 거리입니다.

  1. 큐에 넣을 때 방문

    같은 칸이 중복으로 큐에 들어가지 않도록 발견 즉시 방문 표시합니다.

  2. 거리 전파

    이웃 칸의 거리는 현재 칸의 거리 + 1로 기록합니다.

  3. 목표 발견

    BFS는 거리 순서대로 처리하므로 G를 처음 발견한 순간 더 짧은 경로는 없습니다.

이 문제의 전체 코드
from collections import deque

def shortest_path(grid, start, goal):
    queue = deque([(start[0], start[1], 0)])
    visited = {start}
    while queue:
        row, col, distance = queue.popleft()
        if (row, col) == goal:
            return distance
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = row + dr, col + dc
            if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]):
                if grid[nr][nc] == 0 and (nr, nc) not in visited:
                    visited.add((nr, nc))
                    queue.append((nr, nc, distance + 1))
    return -1
function shortestPath(grid, start, goal) {
  const queue = [[...start, 0]], visited = new Set([start.join(",")]);
  for (let head = 0; head < queue.length; head++) {
    const [row, col, distance] = queue[head];
    if (row === goal[0] && col === goal[1]) return distance;
    for (const [dr, dc] of [[1,0],[-1,0],[0,1],[0,-1]]) {
      const nr = row + dr, nc = col + dc, key = nr + "," + nc;
      if (grid[nr]?.[nc] === 0 && !visited.has(key)) {
        visited.add(key);
        queue.push([nr, nc, distance + 1]);
      }
    }
  }
  return -1;
}

풀이 순서

  1. 노드와 간선이 무엇인지 정의한다.
  2. 방문 시점을 큐나 스택에 넣는 순간으로 정한다.
  3. 인접 상태가 범위 안이고 미방문인지 확인한다.

복잡도

O(V + E), 격자는 O(행 × 열)

자주 하는 실수

BFS에서 큐에서 꺼낼 때 방문 처리하면 같은 노드가 여러 번 들어갈 수 있습니다.
