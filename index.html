4-week route

처음이라면 이 순서로

주 5일, 하루 60~90분 기준입니다. 매주 마지막 학습일에는 새 유형 대신 오답과 이전 유형을 다시 봅니다.

  1. 1주차

    기본 도구 익히기

    배열·해시 → 스택·큐 → 완전 탐색

    완료 기준: 각 유형의 적용 조건을 설명하고 직접 적용 문제를 2개씩 풉니다.
  2. 2주차

    탐색 범위 줄이기

    정렬·그리디 → 이분 탐색 → 투 포인터

    완료 기준: 각 기법이 실패하는 반례를 하나씩 만들고 직접 적용 문제를 풉니다.
  3. 3주차

    상태와 관계 탐색하기

    DFS·BFS → 동적 계획법

    완료 기준: 방문 상태와 DP 상태를 문장으로 정의하고 대표 코드를 빈 화면에서 다시 씁니다.
  4. 4주차

    그래프 문제 확장하기

    최단 경로 → 유니온 파인드·MST → 약점 복습

    완료 기준: 가중치·연결성 조건을 구분하고 누적 오답 중 3문제를 다시 해결합니다.

정답을 외우는 대신, 선택의 근거를 익히세요.
